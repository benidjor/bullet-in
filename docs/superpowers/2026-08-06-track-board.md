## 7. 병렬 세션 운영 규칙 — 4축에 3종을 더한다

기존 4축은 **필드 소유권 · DB 상태 창 · 외부 접촉 예산 · 배포**다 (07-30 판에서 확립 · 08-03 판에서 정식화).
2026-08-06 배치를 짜면서 4축이 못 덮는 공유 자원 셋이 드러났다.

- **메모리 파일** — 두 세션이 같은 트랙 메모리를 쓰면 나중 쓰기가 앞 것을 덮는다.
트랙별 소유로 선언하고 소유 세션만 쓴다.
- **로컬 DB 사본** — 화면 검증용 사본을 다른 세션이 다시 뜨면 (DROP 후 재복원) 검증 중인 렌더가 깨진다.
사본 이름을 세션별로 가른다.
- **분기 기준** — 여러 세션의 PR 이 순차 머지되면 로컬 `main` 이 뒤처진다.
매번 `git fetch origin` 뒤 `origin/main` 에서 딴다.

**권장 규모는 2줄이다.** 3줄 이상이면 접촉 예산과 배포에서 대기가 세션 수에 비례해 늘어난다.
이번 3줄이 성립한 것은 재추출을 실측까지로 자르고 배포 주체를 하나로 묶은 덕이다.
