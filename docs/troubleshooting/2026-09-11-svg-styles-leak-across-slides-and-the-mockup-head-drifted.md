# SVG 안의 스타일이 슬라이드 전체로 새고, 목업 머리가 조립기와 어긋나 있었다 (2026-09-11)

- **영역**: 포트폴리오 슬라이드 (저장소 밖 `v9_build`) / 캡처 · 측정 도구
- **관련 문서**: `docs/runbook/2026-09-09-revising-a-slide-deck-with-mockups-and-measurements.md` · `docs/troubleshooting/2026-09-09-slide-overflow-came-from-css-not-sentences.md`
- **관련 안건**: 없음 (포트폴리오 통독 4차에서 14차)

## 증상 셋

같은 덱을 통독하는 동안 서로 다른 모양으로 세 번 나타났다.

1. 9장 도식의 라벨 (「통과」 · 「실패」 · 「다시 번역」) 뒤에 회색 배경이 깔렸다.
   그 SVG 의 라벨 상자는 `fill:#fff` 로 선언돼 있었다.
2. 17장 목업에서 semibold 로 지정한 문장이 보통 굵기로 찍혔다.
   같은 문장이 덱에서는 semibold 여서 두 줄, 목업에서는 한 줄로 재어졌다.
3. 목업 셋 (15 · 16 · 17장) 이 넘침 0 이었는데 조각에 옮겨 조립하자 16장이 16px, 17장이 31px 넘쳤다.
   문장은 한 글자도 다르지 않았다.

## 원인

### SVG `<style>` 은 그 SVG 에 갇히지 않는다

HTML 문서 안의 `<svg><style>…</style></svg>` 는 문서 전체에 적용되는 스타일시트다.
슬라이드마다 SVG 를 인라인으로 넣고 짧은 클래스 이름을 쓰다 보니 세 번 부딪혔다.

- v8 시절 슬라이드 둘이 `.lb{fill:#f0f0f0}` 을 선언해 뒀고, 9장이 같은 이름 `.lb` 를 흰색 라벨 상자에 썼다.
  문서 뒤쪽 선언이 이겨 9장 라벨이 회색이 됐다 (증상 1).
- 17장 목업의 ERD 가 상자 클래스로 `.sb` 를 썼는데, 덱은 같은 이름 `.sb` 를 semibold 강조 클래스로 새로 정의했다.
  목업 파일에 semibold 규칙을 넣는 스크립트가 「`.sb{` 가 이미 있다」 고 판단해 건너뛰었다 (증상 2).
- 15장 도식이 `.kw` 를 썼는데 덱의 코드 블록은 `.code .kw` 로 키워드 색을 낸다.
  SVG 쪽 `.kw{font-size:11.5px;font-weight:800}` 이 코드 블록 키워드에도 적용될 자리였다.
  이것은 반영 전에 찾아 접두어를 바꿨다.

### 목업 머리가 조립기의 주입 규칙을 안 담고 있었다

조립기 (`build_v9.py`) 는 v8 덱의 `</style>` 앞에 규칙 한 줄을 끼워 넣는다.
그 줄에 16장 공통 목록 규격 (`.bi .ul-list li{font-size:13.5px}` 등) 이 들어 있다.
목업 머리 (`mockups/head.html`) 에는 그 줄의 옛 판이 들어 있어서 `.bi` 규격이 없었고, 목업의 목록 글자는 13px 로 렌더됐다.
덱과 목업에서 같은 항목의 높이 · 글자 크기를 나란히 재어 보고서야 드러났다.

```
deck  41 13.5px | mock  40 13px | 기각 근거를 다시 측정: Airflow 3.3.1   ⚠
```

## 해결

- SVG 클래스는 슬라이드별 접두어를 붙인다 (`.glb` · `.xb` · `.dpb` 처럼).
  덱 전체에서 `grep -o '\.lb{[^}]*}' 덱.html | sort | uniq -c` 로 같은 이름의 선언이 몇 개인지 먼저 센다.
- 목업 머리의 마지막 규칙 줄은 조립기의 현재 문자열로 교체한다.
  런북에 절차와 검증법 (덱 · 목업에서 `li` 글자 크기 비교) 을 적었다.
- 반영 뒤에는 목업 값이 아니라 덱에서 다시 잰다.
  목업이 0 이어도 덱은 다를 수 있다.

## 배운 것

- 인라인 SVG 의 `<style>` 은 지역 스타일이 아니다.
  이름이 짧을수록 다른 장과 부딪힌다.
- 「이미 있다」 를 문자열 포함으로 검사하면 다른 뜻의 같은 이름에 속는다.
  규칙을 넣을 때는 선택자와 속성까지 맞는지 본다.
- 측정값이 두 환경에서 다르면 문장을 고치기 전에 글꼴 정의부터 대조한다.
  같은 문장이 다른 줄 수로 재어지는 것은 글자 크기의 신호다.
