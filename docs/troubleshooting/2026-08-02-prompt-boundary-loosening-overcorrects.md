# 분류 경계를 한쪽만 완화하니 반대편이 샜다 (2026-08-02)

`other` 버킷에 이적 기사가 남는다는 실측을 받고 프롬프트에서 `other` 조건을 좁혔더니, 이번에는 이적이 아닌 글이 이적 단계를 받았다.
완화 (#200) 와 정정 (#201) 이 같은 날 한 번씩 필요했고, 두 번째가 없었다면 스폰서십 계약 기사가 "이적 합의" 배지를 달고 서빙될 뻔했다.

## 1. 증상

`other` 59건을 표적 재분류한 뒤 이동한 22건을 눈으로 훑다가 발견했다.

- `9079f708` · `64ccfe25` — 에미레이트 스폰서십 계약 · 조기 연장 → `agreed`
- `dbc972df` — 추아메니가 레알 마드리드와 맺은 재계약 → `agreed`
- `02f03bad` — 이미 첼시로 이적한 선수가 아스날 팬을 도발한 기사 → `agreed`
- `4df540fe` — 월드컵 여파를 다룬 칼럼 → `rumour`

넷 다 선수 이동이 없는 글이다.
분류 패스는 오류 없이 1패스로 수렴했고 잔존도 0이었다 — 숫자만 보면 성공이었다.

## 2. 원인

- #200 은 "other 는 이적과 정말 무관한 글에만 쓴다" 로 조건을 좁히면서 예외를 **감독 · 스태프 인사** 하나만 뒀다.
- 모델 입장에서 "계약 체결 · 연장" 은 `agreed` 의 정의 (구단 간 이적 합의) 와 표면이 닮았다.
스폰서십도 계약이고 재계약도 계약이라, 이적이 아니라는 근거를 프롬프트에서 찾을 수 없었다.
- 즉 경계를 한쪽 (이적 기사를 단계로) 으로만 열었고, 반대쪽 (이적 아닌 글은 other) 을 같은 강도로 적지 않았다.

## 3. 조치

제외 목록을 명시해 양쪽 경계를 함께 못 박았다 (#201).

- 스폰서십 · 유니폼 · 중계권 같은 상업 계약 (체결 · 연장이라도 이적이 아니다)
- 소속 구단과의 재계약 · 계약 연장
- 감독 · 스태프 인사
- 기사가 아닌 공지 · 안내 · 목록 링크

정정 후 같은 59건을 다시 분류하니 넷 모두 `other` 로 돌아왔고, 정상 이동분 (대안 후보군 → interest · 알바레스 결렬 → negotiating 등) 은 판정을 유지했다.

## 4. 예방 규칙

- **완화와 제외는 쌍으로 적는다.** 어떤 유형을 단계로 끌어오는 규칙을 넣으면, 그 규칙이 잘못 삼킬 이웃 유형을 같은 프롬프트에 제외로 적는다.
- **프롬프트를 바꾸면 실물로 dry-run 한다.** 배포판에서 대상 행을 읽기 전용으로 뽑아 로컬에서 1배치만 분류하면 DB 를 건드리지 않고 효과를 본다 (절차는 분류 런북 §3.2).
- **dry-run 에 대조군을 넣는다.** 고치려는 행만 보면 과소 교정 (정상 이동분까지 되돌아가는 것) 을 놓친다.
이번 정정에서도 대조군 4건이 판정을 유지하는 것을 확인하고 나서야 머지했다.
- **수렴은 성공이 아니다.** 잔존 0 · 오류 없음은 "모델이 답을 돌려줬다" 는 뜻일 뿐이다.
배치 뒤에는 이동 내역을 유형별로 훑어야 하고, 이번 과교정도 그 검사에서만 드러났다.
