# 원문이 안 열리는 이유는 상태 코드가 아니라 응답 본문이 말해 준다 (2026-08-20)

저자 회수 소급에서 원문 147건에 접속해 24건이 막혔다.
상태 코드만 보고 「유료 매체라 페이지를 안 준다」 로 묶었는데 **틀렸다.**
사용자가 브라우저로 같은 주소를 열자 기사도 기자명도 그대로 있었다.

관련 = `2026-08-03-fmkorea-430-not-explained-by-our-requests.md` (같은 계열 · 그쪽은 수집 대상 사이트가 우리를 막는 이야기이고, 이 문서는 **전재글의 원문 매체**가 막는 이야기다).

---

## 1. 무엇을 잘못 말했나

접속 실패 24건을 상태 코드로만 갈랐다.

| 매체 | 코드 | 내가 붙인 해석 |
| --- | --- | --- |
| The Telegraph 11 | 402 | 「Payment Required — 유료라 페이지 자체를 안 준다」 |
| BeSoccer 10 | 406 | 「헤더를 보고 거절한다」 |
| AS · Sky · TIA · 헤코르드 5 | 403 | 「매체마다 사정이 달라 한 번에 못 푼다」 |

그리고 **「더 파지 않는다」 고 권했다.**
근거는 「402 는 페이월이니 받을 것이 없다」 였는데, 그 판단의 재료가 **세 자리 숫자 하나**뿐이었다.

**응답 본문을 안 읽었다.**
읽었으면 5초 만에 갈렸다.

## 2. 실제로는 무엇이었나

### 2.1. 402 는 페이월이 아니라 봇 차단이었다

```
<h1>Access Issue Help</h1>
<p>You are seeing this page because our security systems have detected
   some unusual activity on this connection.</p>
...
[{"message":"You are not authorized to access this content without a valid
             TollBit Token. Please fol…
```

TollBit 은 언론사가 **자동화 · AI 접근에 별도 토큰과 요금을 물리려고** 붙이는 장치다.
사람 브라우저에는 페이지를 주고 기계에만 문을 닫는다.
그래서 「유료라 아무도 못 본다」 가 아니라 **「사람은 보는데 우리만 못 본다」** 였고, 회수 경로가 살아 있었다.

### 2.2. 406 은 아무 말도 안 한다

BeSoccer 는 **본문 0바이트**로 406 만 돌려준다.
사유를 안 밝히므로 헤더를 보고 막는지 연결 자체를 보고 막는지 판정할 수 없다.

**같은 「접속 실패」 라도 다음에 할 일이 갈린다** — 402 는 「사람이 읽으면 된다」 가 확정됐고, 406 은 페이지에 기자명이 있는지조차 모르는 상태로 남는다.

### 2.3. User-Agent 를 바꿔도 안 된다

둘 다 헤더 조합을 바꿔 시험했지만 결과는 같았다.

```
The Telegraph  현재 UA → 402 · 1,028바이트     브라우저 UA → 402 · 1,028바이트
BeSoccer       현재 UA → 406 · 0바이트         브라우저 UA → 406 · 0바이트
                Accept 헤더 추가 → 406 · 0바이트
```

**응답 크기까지 같다** — 헤더를 보고 가르는 것이 아니라 연결을 보고 막는다는 뜻이다.
UA 를 바꾸는 것은 해결이 아니라 판정을 속이는 일이다.

## 3. 판정을 속이지 않는다

텔레그래프는 **거절 의사를 기계가 읽을 수 있는 형태로 밝혔다.**
그것을 우회하려면 그 판정을 속여야 하고, 얻는 것은 기자 이름 열한 개다.

**대신 사람이 읽어 준 값을 넣는 경로를 썼다.**
사용자가 브라우저로 정상 접근해 확인한 기자명을 URL 로 대조해 저장했다 — 외부 접속 0 · 과금 0 · 11건 전건 회수.
절차는 `docs/runbook/2026-08-08-onetime-db-batch-via-tunnel.md` §8.5 에 있다.

**자동으로 못 가져오는 것과 값을 못 얻는 것은 다르다.**

## 4. 다음에 쓸 절차

**접속이 막히면 상태 코드와 함께 응답 본문 앞머리를 남긴다.**
소급 배치의 실패 기록에 코드만 적으면 다음 사람이 같은 오해를 반복한다.

```python
if r.status_code != 200 and len(r.text) < 1200:
    log.info("차단 응답: %s", re.sub(r"\s+", " ", r.text)[:220])
```

**「원문에 없다」 와 「우리가 못 읽는다」 를 갈라 적는다.**
이번 24건은 전부 뒤쪽이었는데 앞쪽처럼 보고했다.
같은 실수를 이 트랙에서 두 번 했다 (`2026-08-15-unknown-author-means-we-could-not-read-it.md` §1 · §5).

**막힌 매체는 표본 하나를 사람이 열어 본다.**
페이지에 값이 있는지조차 모르면 「불가」 로 묶을 근거가 없다.
텔레그래프는 열어 보니 있었고 (11건 회수), BeSoccer 는 아직 아무도 안 봐서 판정이 안 선 채로 남아 있다.

**전재글의 원문 매체는 우리 수집 소스가 아니다.**
텔레그래프 · BeSoccer 는 `config/sources.yaml` 에 없다 — 이용자가 옮겨 준 글의 출처일 뿐이다.
그래서 「소스로 추가하면 된다」 가 답이 아니고, 원문 접속은 **이미 가진 기사에 부가 정보를 채우려는 시도**다.
막혀도 본문은 게시글에서 얻어 이미 화면에 나가 있고, 잃는 것은 그 필드 하나뿐이다.
