# 구단이 영입 발표에 Academy 를 붙여 공홈 수집이 통째로 놓쳤다 (2026-08-29)

사용자가 「이고르 타이욘 기사는 왜 안 올라왔지」 라고 물었다.
구단 공식 발표인데 사이트에 없었다.

## 1. 회차는 정상이었다

먼저 회차부터 확인했다 — 여기가 아니었다.

```
00:04:04  수집 시작
00:05:56  배포 완료 (db2981a3)
arsenal_official: 창 후보 56 · Men 39 · accept 1
```

그리고 DB 에도 없었다. 그 기사를 언급한 것은 afcstuff 트윗 두 건뿐이었다.

## 2. 원인 — `Men` 이 필수인데 구단이 `Academy` 를 붙였다

공홈 API 로 그 기사 하나를 조회해 채택 함수를 그대로 돌렸다.

```
제목        : Igor Tyjon signs for Arsenal
발행        : 2026-08-28 15:00 UTC
taxonomies  : ['Academy', 'Hygiene', 'Know', 'Text Article',
               'Transfer news', 'News', 'Arsenal (internal)', '2026-2027', 'Main']

News 인가              True
'Men' 태그 있나         False
이적 태그 있나          True
제목이 이적 어휘인가     True

채택 판정 : None
```

`_accept` 의 첫 줄에서 잘린다.

```python
if article.get("articleType") != "News" or REQUIRED_TAXONOMY not in tax:
    return None            # Men 이 없으면 뒤 조건은 보지도 않는다
```

**이적 태그도 있고 제목 조건도 통과하는데 둘 다 안 본다.**
그 회차의 「Men 39」 에도 못 들어갔으니, 관측용 `men_news_rejects` 에도 안 잡혔다 — 그 목록이 `Men` 있는 것만 담기 때문이다.

## 3. `Men` 필수는 실수가 아니다

어댑터 주석에 이유가 적혀 있다 — **아카데미 기사 차단**이다.
공홈은 U-18 · U-21 소식을 대량으로 내고, 그것이 전부 들어오면 화면이 덮인다.

타이온은 **아카데미 태그를 달고 온 1군 영입 발표**라 그 장치에 함께 걸렸다.
기사 본문도 「U-21 팀에서 1군 무대로」 · 「아스날의 아카데미 유망주 육성 이력」 을 함께 말한다 — 구단 입장에서는 어느 쪽 태그를 붙여도 이상하지 않은 글이다.

## 4. 그래서 규칙을 그 자리에서 안 고쳤다

후보는 둘이다.

- **가** 이적 태그가 있으면 `Men` 없이 채택
- **나** `Men` 이 없어도 **제목 조건까지** 통과하면 채택 (`Academy` 단독은 계속 차단)

**둘 다 「그러면 무엇이 새로 들어오나」 를 안 재고는 못 고른다.**
이번 회차만 봐도 창 후보 56 중 `Men` 이 아닌 것이 17건이고, 그것이 어떤 글인지 아직 세지 않았다.
오늘 전환어 후보를 서빙 전량에 대 보고 넷을 기각했던 것과 같은 절차가 필요하다.

**대신 그 한 건만 손으로 넣었다** — 절차는 `docs/runbook/2026-08-29-adding-one-article-outside-the-cycle.md` 에 있다.

## 5. 남길 것

- **필수 조건은 뒤 조건을 안 보게 만든다.** `Men` 이 `and` 의 앞에 있어서 이적 태그 · 제목 어휘 두 신호가 무력해졌다.
- **관측 장치도 같은 조건 안에 있으면 못 본다.** `men_news_rejects` 는 `Men` 있는 것만 담아, 정작 `Men` 이 없어 빠진 이 기사를 기록하지 못했다.
- **소스가 태그를 어떻게 붙일지는 우리가 못 정한다.** 셀렉터 드리프트와 같은 갈래이고, 단위 테스트로는 안 잡힌다 — 실물 응답을 한 번 찍어 봐야 갈린다.
- **회차 로그의 「창 후보 · Men · accept」 세 수는 이 고장을 이미 말하고 있었다.** 56 → 39 → 1 에서 두 번째 화살표가 크다는 것을 아무도 안 봤다.
