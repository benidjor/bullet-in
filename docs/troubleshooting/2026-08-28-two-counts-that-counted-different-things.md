# 사이드바 숫자와 필터 결과가 갈렸다 — 그리고 내 검산도 갈렸다 (2026-08-28)

사용자가 「공신력 최상 (94) 을 눌렀는데 91건이 나온다」 고 알렸다.
원인을 찾는 동안 **제품의 결함 하나와 내 측정 도구의 결함 하나가 겹쳐** 한 번은 틀린 결론을 보고했다.

## 1. 제품 쪽 — 「기타」 예외가 한 축에만 걸려 있었다

`app.js` 의 `match()` 는 단계가 「기타」 인 기사를 이렇게 다룬다.

```js
const okStage = isOther ? (showOther || (srcActive && stageEnums.size === 0)) : …
```

주석에 의도가 적혀 있다 — 「사이드바가 적어 둔 건수에는 기타 기사가 들어 있는데 기타 토글 말고는 그것을 열 수단이 없었다」.
그런데 그 예외가 **언론사 · 기자 (`srcActive`) 에만** 걸려 있고 공신력 축에는 없었다.
공신력만 고르면 기타 기사가 조건에서 빠져 목록만 줄었다.

배포본 실측 (개정 전 규칙) 이다.

```
등급    사이드바   필터   차이
최상        94     86      8
상         122    100     22
중         105     80     25
하          99     82     17
최하        429    385     44
```

고침은 한 줄이다.

```js
const narrowed = srcActive || tiers.length > 0;
const okStage = isOther ? (showOther || (narrowed && stageEnums.size === 0)) : …
```

## 2. 남은 차이 — 홈에 안 그려지는 기사

기타 예외를 고친 뒤에도 최상이 94 vs 92 로 남았다.
사이드바는 **서빙 행 전체**를 세고 필터는 **홈에 그려진 요소**를 센다.
그 둘은 원래 다른 모집단이다.

빠진 두 건은 **결말 카드로 뽑힌 기사**였다.
홈은 결말 카드를 안 그리기로 했는데 (2026-08-23) `related_reports` 가 결말 기사를 갈래에서까지 빼서, 그 기사가 홈의 어느 자리에도 안 남았다 (실측 12건).

```python
excluded = set()
if rep:
    excluded.add(rep["content_hash"])
# if ending: excluded.add(...) 를 걷어냈다
```

**카드를 안 그리기로 한 결정이 「갈래에서도 뺀다」 는 옛 근거를 무효로 만들었는데, 그때 그 자리를 함께 보지 않았다.**

## 3. 측정 쪽 — 내 재현 스크립트가 같은 카드를 두 번 셌다

두 고침 뒤 다섯 등급은 맞았는데 최하만 「필터가 11 더 센다」 가 나왔다.
그것을 「원래 있던 자리」 라고 사용자에게 보고했다. **틀린 보고였다.**

`app.js` 의 첫 루프는 `if / else if` 다.

```js
for (const it of items) {
  if (it.classList.contains('dupcard')) { … }
  else if (!it.closest('.block')) { … }
}
```

내 재현은 두 조건을 **각각의 목록 순회로** 옮겨 적었다.

```python
shown += [i for i in items if "dupcard" in i.class]           # ①
shown += [i for i in items if not i.find_parent("block")]      # ②
```

블록 밖에 있는 dupcard 는 ①과 ② 양쪽에 걸려 두 번 세어졌다.
최하 등급에만 그런 카드가 11장 있어서 정확히 11 이 남았다.
`if / else if` 로 고쳐 다시 재니 **여섯 등급 전부 차이 0** 이었다.

## 4. 이 회차에서 얻은 것

- **수가 안 맞으면 데이터보다 도구를 먼저 본다.**
  [[my-measuring-tool-was-wrong-not-the-data]] 가 이미 적어 둔 함정인데 또 밟았다.
  이번 신호는 「한 등급만 부호가 반대」 였다 — 데이터 결함은 보통 그렇게 한 칸만 깔끔하게 어긋나지 않는다.
- **분기 구조를 옮겨 적을 때는 분기 자체를 옮긴다.**
  `if / else if` 를 두 개의 독립 조건으로 풀면 겹치는 입력에서 값이 달라진다.
- **「원래 있던 자리」 는 강한 주장이다.** 그렇게 말하려면 개정 전 산출물에 **같은 도구**를 대 봐야 한다.
  이번에는 그 대조를 하고 나서야 내 도구가 틀린 것이 드러났다.
- **두 계수를 비교하기 전에 「무엇을 세는가」 를 먼저 맞춘다.**
  사이드바는 사이트 전체, 필터는 홈 화면이다. 이 둘은 영영 같아질 수 없는 자리가 남는다 (전체 기사 페이지에만 있는 기사).
