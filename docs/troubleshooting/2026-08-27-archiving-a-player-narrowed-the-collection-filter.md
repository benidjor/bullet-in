# 명단 한 칸을 고쳤더니 기사 26건이 화면에서 사라졌다 (2026-08-27)

이적이 끝난 선수 여덟을 `status='archived'` 로 바꿨다.
명단 화면을 고치려던 것인데 **fmkorea 기사 26건이 목록에서 빠지고 상세 페이지가 지워졌다.**

방향은 옳았다 — 사라진 것이 대체로 타 구단 이적 기사이고 서빙 필터가 원래 그것을 겨냥한다.
문제는 **그 연쇄를 미리 세지 않았다는 것**이다.

## 1. 연쇄

```
players.status = 'archived'
  → PlayerStore.confirmed_ko_names() 가 status='confirmed' 만 모은다
  → 그 집합이 fmkorea 무관 글 필터의 인정 집합이다 (run.py · watchlist_fmkorea.py)
  → 제목에 그 이름이 있어 통과하던 글이 걸린다
  → 목록에서 빠진다
  → sweep_orphan_pages 가 상세 페이지도 지운다 (404)
```

인정 집합이 79 에서 71 로 줄었고 서빙 행이 847 에서 821 로 줄었다.

## 2. 왜 안 보였나

### 2.1. `status` 가 표시 축이 아니라 여러 판정의 입력이다

명단 작업을 할 때 `status` 는 「이 선수를 화면에 띄울까」 로 읽힌다.
그런데 이 저장소에서 그 값은 **적어도 넷을 움직인다.**

| 읽는 곳 | 무엇을 결정하나 |
| --- | --- |
| `_PAGE_WHERE` | 선수 페이지 대상 |
| `confirmed_ko_names()` | fmkorea 무관 글 필터의 인정 집합 (**수집 · 서빙 양쪽**) |
| `active_link_players()` | 워치리스트 로테이션 대상 |
| `LINKED_HASHES_SQL` | 서빙 필터의 넷째 신호 |

**앞의 하나만 보고 고쳤다.**

### 2.2. 「방향이 맞다」 와 「승인받았다」 는 다르다

사라진 26건은 얀 디오망데의 PSG · 리버풀 이적설 13건, 토레스 PSG 4건 같은 타 구단 기사다.
아스날 소식이 아니니 빠지는 것이 맞다.

**그래도 받은 승인은 「명단 값 정정」 이었다.**
한 번의 조작이 두 가지를 했고 둘째는 미리 말한 적이 없다.

다만 이것을 **「승인 범위 밖」 이라고 부른 것은 과했다** (사용자 지적).
명단 값을 고치면 그 이름이 필터에서 빠지는 것은 이 저장소가 그렇게 설계한 연쇄다.
정상 동작을 위험처럼 말하면 **진짜 위험을 말할 때 신호가 묻힌다.**

## 3. 정작 알릴 값어치가 있던 것은 26 이 아니라 2 였다

「떠났다는 근거 기사가 화면에 남아 있나」 를 재 보니 둘이 빠져 있었다.

| 선수 | 근거 기사 | 결과 |
| --- | --- | --- |
| 토레스 | 「페란 토레스, PSG 이적 확정 후 …」 | **빠짐** |
| 부아디 | 「맨체스터 시티, 아유브 부아디 영입 합의」 | **빠짐** |
| 라크루아 · 완-비사카 | (fmkorea) | 남음 — 제목에 다른 아스날 맥락이 있어 통과 |
| 얀 디오망데 · 우스망 디오망데 | (bbc) | 남음 — fmkorea 가 아니라 필터 대상이 아님 |

**선수 색인은 「타 클럽행」 이라고 말하는데 그 근거가 화면에 없다.**
부아디를 보관하게 만든 기사가 보관했다는 이유로 안 보이게 된 셈이다.

### 3.1. 되살리는 안은 값이 안 맞았다

「선수 페이지 대상 전부의 주역 기사를 살린다」 로 바꾸면 근거 둘이 돌아오지만 **25건이 함께 돌아온다.**
「종결 단계 기사만 살린다」 는 효과가 0 이었다 — 그 둘의 귀속 단계가 `done` · `official` 이 아니다.

**2 를 위해 25 를 되돌릴 값어치가 없다고 보고 그대로 두었다.**

## 4. 되짚어 얻은 규율

- **명단 축을 고치면 그 이름이 들어간 다른 집합을 함께 센다.**
고치기 전에 「이 값을 읽는 곳이 어디인가」 를 grep 한다.
- **연쇄가 설계된 것이라도 규모는 미리 잰다.**
「방향이 맞다」 가 「크기를 알아도 된다」 는 뜻은 아니다.
- **정상 동작을 위험 어휘로 부르지 않는다.**
경보의 값어치는 그것이 드물 때 나온다.
- **목록에서 빠지면 상세 페이지도 지워진다** — `sweep_orphan_pages`.
공유된 링크가 404 가 되므로 「DB 에 남아 있다」 와 「사이트에 남아 있다」 를 갈라 말한다.
