# Gemini 선불 잔액이 바닥나 번역이 27시간 멈췄는데 알림이 없었다 (2026-10-05)

- **영역**: 번역 · 요약 (`enrich`) / Gemini 결제 / 알림
- **관련 안건**: 3α 제미나이잔액무신호
- **고친 것**: 결제 (사용자가 크레딧을 다시 충전) · 코드 변경 없음
- **남은 일**: 같은 거절이 이어질 때 사람을 부르는 신호 (안건 3α)

## 1. 증상

2026-10-04 밤 수치를 다시 세다가 수집 현황 화면의 SLO-4 (필수 필드 완전성) 가 99.5% 인 것을 봤다.
dbt `not_null` 테스트 10종 가운데 2종에서 결측이 6행 나왔다.

운영 DB 를 보니 결측은 fmkorea 기사 11건의 이적 분류 두 칸 (`transfer_stage` · `transfer_direction`) 이었다.
11건 모두 번역 (`title_ko`) 도 비어 있었다.
가장 오래된 행은 2026-10-03 12:01 UTC 에 들어왔다.

밀린 번역은 다음 실행이 이어 받는 것이 정상이라 하루 넘게 남아 있다는 것이 이상했다.

## 2. 원인 — 매 실행 429

Airflow `enrich` 태스크 로그를 10-01 부터 10-04 까지 정규 실행 29회분을 전부 셌다.

| 실행 (UTC) | `rate limit(429)` 줄 |
| --- | --- |
| 10-01 00:00 ~ 10-02 21:00 (16회) | 0 |
| 10-03 00:00 | 1 |
| 10-03 03:00 ~ 09:00 (3회) | 0 |
| **10-03 12:00 ~ 10-04 12:00 (9회)** | **매회 2** (번역 · 단계 분류 둘 다 첫 호출에서 중단) |

분당 속도 한도라면 다음 실행에서 풀린다.
9회 연속이라 할당량이나 결제 문제로 봤다.

사용자가 AI Studio 의 Gemini API 결제 화면을 확인해 보니 선불 크레딧 잔액이 0 아래로 내려가 있었다.
화면에는 「서비스를 재개하려면 크레딧 잔액이 0 보다 커야 한다」 는 안내가 떠 있었고 자동 충전은 꺼져 있었다.

## 3. 왜 아무 신호가 없었나

| 장치 | 동작 | 이번에 |
| --- | --- | --- |
| `enrich` 의 429 처리 | 429 를 받으면 그 실행의 번역을 멈추고 남은 행을 다음 실행에 넘긴다 · `WARNING` 로그 | 분당 속도 한도용 설계가 영구 거절에도 똑같이 반응했다 · 9회 연속도 로그 9줄로 끝났다 |
| dbt 게이트 | 분류 두 칸의 `not_null` 은 「0건 초과 경고 · 200건 초과 차단」 | 결측 11행은 경고 구간이라 배포를 막지 않았다 (의도된 설계) |
| SLO-4 | 「결측이 가장 많은 테스트의 행 수 ÷ 기사 수」 · 목표 99% | 11 ÷ 1,282 = 99.1% · 13행부터 미달이었다 · 미달이 되기 전에 사람이 먼저 봤다 |
| Discord | 위 어느 장치도 알림을 보내지 않는다 | 없음 |

설계 문서와 CLAUDE.md 는 「429 는 그 실행만 멈추고 스케줄이 재시도한다」 를 의도된 동작으로 적어 두었다.
그 전제는 429 가 잠깐 걸리는 속도 한도라는 것이었다.
잔액 소진은 같은 429 로 오지만 기다려도 풀리지 않는다.

## 4. 복구

2026-10-05 00:00 KST 실행 직전에 사용자가 크레딧을 충전했다.

| 확인 (10-04 15:00 UTC 실행) | 결과 |
| --- | --- |
| `enrich` 의 429 | 0 |
| 결측 (`transfer_stage` · `transfer_direction`) | 11 → 0 |
| dbt 게이트 | 테스트 22종 전부 통과 |
| 다음 화면의 SLO-4 | 100.0% |

밀린 11건은 이 실행 한 번에 번역됐다.
「다음 실행이 이어 받는다」 는 설계는 잔액만 있으면 제대로 동작했다.

## 5. 배운 것

- **같은 응답 코드가 다른 원인을 실어 온다.** 429 는 분당 속도 한도와 잔액 소진을 구별하지 않는다. 한 번의 429 와 연속된 429 를 같은 신호로 다루면, 영구 거절도 일시 장애처럼 조용히 흘러간다.
- **연속 횟수로 성격을 가른다.** fmkorea 의 일시 차단 (430) 을 「8회 연속일 때만 끊김」 으로 가른 것과 같은 방식으로, 429 도 몇 회 연속이면 사람을 부르는 신호가 필요하다 (안건 3α).
- **SLO 가 마지막 그물이었다.** 이번에는 SLO-4 가 미달 직전이었고 수치를 다시 세던 사람이 먼저 봤다. 사람이 안 봤다면 2건만 더 쌓였을 때 수집 현황 화면에 미달로 처음 나타났을 것이다.

## 6. 남은 일 (안건 3α)

- 429 가 N회 연속이면 사고 채널 알림 (N 과 채널을 정한다)
- 429 응답 본문으로 잔액 소진 (영구) 과 속도 한도 (일시) 를 가를 수 있는지 확인
- 자동 충전 여부 (결제 판단)
- 요금 조회 방법은 CLAUDE.md 「Gemini 429 · 요금」 항목을 따른다 (금액은 문서에 적지 않는다)
