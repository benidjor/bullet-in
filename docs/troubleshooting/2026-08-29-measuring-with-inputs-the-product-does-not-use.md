# 제품이 안 쓰는 입력으로 재서 판정이 뒤집혔다 (2026-08-29)

같은 회차에 두 번 밟았다.
둘 다 **데이터는 멀쩡했고 재는 쪽이 제품과 다른 것을 보고 있었다.**

앞선 회차의 `2026-08-28-four-yardsticks-that-were-all-wrong-at-once.md` 는 **잣대의 단위 · 층 · 범위 · 타입**을 다뤘다.
여기는 그다음 자리다 — 단위가 맞아도 **입력과 함수가 제품 것이 아니면** 답이 뒤집힌다.

## 1. 사전이 달라 후보 판정이 뒤집혔다

사건 묶음의 주인공을 정하는 전환어 후보 열 개를 재고 있었다.
「이탈」 후보에서 이런 결과가 나왔다.

```
「이탈」 — 바뀌는 기사 1건
  화이트 → 사카
  아스날, 벤 화이트 이탈 우려 속 전 맨유 스타 완-비사카 영입 고려
```

**「완-비사카가 사전의 「사카」 에 부분 일치한다」 로 읽고 기각했다.**
사용자에게도 그렇게 보고했다.

실제로는 반대였다.

```
사전에 완-비사카 있나: ['완-비사카', '사카']
제목에 걸리는 이름     : [(7, '화이트'), (27, '완-비사카'), (30, '사카')]
「이탈」 넣었을 때      : 화이트 → 완-비사카     ← 옳은 쪽
```

**내 측정 스크립트가 사전을 `players WHERE status='confirmed'` 로 뽑았다.**
제품은 `load_player_names()` (= `PlayerStore.serving_names()`) 를 쓴다.
두 집합이 달라 「완-비사카」 가 내 사전에만 빠져 있었고, 그래서 위치가 뒤인 「사카」 가 잡혔다.

실제 사전과 실제 서빙 행으로 다시 재니 후보별 결과가 바뀌었다.

| 후보 | 옛 측정 | 다시 잰 것 |
| --- | --- | --- |
| 방출 | 1건 | 1건 (같음) |
| 공백 | 1건 | **2건** |
| … | 8건 | **9건** |
| 이탈 | 1건 · 나쁨 | 1건 · **옳음** |

## 2. 렌더된 HTML 을 훑다가 이웃 블록을 집었다

고친 규칙이 실제로 걸렸는지 보려고 배포본 HTML 에서 해시 근처를 잘라 단추 글자를 읽었다.

```
b37ec58f  storylink=['래시포드 더보기 · 기사 13건']   기대=래시포드   ✔
fb540bba  storylink=['콘사 더보기 · 기사 56건']       기대=콘사       ✔
245abbc6  storylink=['돈체프 더보기 · 기사 6건']       기대=스톤스     ✘
```

세 번째가 틀린 것처럼 보였다.
**틀린 것은 내 자르기였다** — `rfind('<div class="block')` 이 이웃 블록의 시작을 집어 그 블록의 단추를 읽었다.

제품 함수를 직접 돌리니 셋 다 맞았다.

```
245abbc6  주인공='스톤스'   아스날, 살리바 부상 공백 대비 존 스톤스 영입 고려
묶음 스톤스 9건 — 대상 기사 포함
```

## 3. 두 사건의 공통점

**둘 다 「제품이 무엇을 보고 판단하는가」 를 안 따라갔다.**

- 첫째는 **입력**이 달랐다 (사전)
- 둘째는 **함수**가 달랐다 (HTML 훑기 vs `cluster_events`)

그리고 **둘 다 그럴듯한 값을 냈다.**
「완-비사카가 사카에 걸린다」 는 이 저장소에 실재하는 함정 (`korean-name-matching-weaknesses`) 이라 의심 없이 받아들였고, 「돈체프」 도 있을 법한 선수 이름이었다.

## 4. 남길 것

- **재는 코드는 제품이 쓰는 입력을 그대로 불러 쓴다.** 사전 · 명단 · 설정을 SQL 로 다시 만들지 말고 로더 함수를 import 한다.
- **판정이 들어가는 것은 제품 함수로 되묻는다.** 렌더 결과를 파싱해 세는 것은 마지막 수단이고, 그때도 자르는 경계를 구조 (블록 시작 · 절 제목) 로 잡는다.
- **아는 함정에 맞아떨어지는 결과일수록 한 번 더 본다.** 기존 함정 목록이 있으면 새 관측을 거기에 끼워 맞추기 쉽다.
- **틀린 보고를 이미 했으면 정정을 남긴다.** 이 회차에서는 코드 주석의 기각 사유가 거짓이 될 뻔했고, 실제 측정으로 고쳐 적었다.
