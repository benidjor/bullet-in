# gtag 를 불렀는데 구글에는 아무것도 안 왔다 (2026-08-24)

계측을 붙이고 「보냈다」 고 보고했는데 GA4 실시간 화면은 **0** 이었다.
사이트도 계측 코드도 정상이었고, 틀린 것은 **내가 확인한 층**이었다.

## 1. 증상

공개 준비 회차에서 GA4 계측 넷을 붙이고 (`bi_entry` · `bi_card_click` · `bi_filter_apply` · `bi_origin_exit`) 라이브 배포본에서 직접 눌러 확인했다.

- 브라우저에서 `gtag` 가 호출됐고 인자도 맞았다 — 익명 식별자 `bi_cid` · 시각 `bi_ts` · 카드 해시 · 언론사까지 실려 있었다.
- 그것을 보고 **「계측 넷이 전부 실제로 발화했다」** 고 보고했다.
- 사용자가 GA4 **실시간 개요**를 열었더니 활성 사용자 **0** · 이벤트 **0** · 「사용 가능한 데이터가 없습니다」 였다.

## 2. 원인 — 확인한 층이 한 겹 앞이었다

**「함수가 불렸다」 와 「요청이 구글에 도착했다」 사이에 층이 하나 더 있다.**

같은 브라우저에서 네트워크를 보니 이렇게 갈렸다.

| 요청 | 결과 |
| --- | --- |
| `googletagmanager.com/gtag/js?id=G-…` | 200 — 태그 스크립트는 정상 로드 |
| `chrome-extension://…/google-analytics_analytics.js` | **확장 프로그램이 끼워 넣은 대체 스크립트** (둘) |
| `google-analytics.com/g/collect` | **없음 — 전송 요청 자체가 안 나감** |

페이지 안을 보니 결정적이었다.

- GA4 가 실제로 초기화되면 생기는 전역 `window.google_tag_data` 가 **없었다.**
- 대신 광고 차단기가 흉내로 만드는 `window.ga` 가 **있었다.**

**진짜 `gtag.js` 가 실행되지 않고 껍데기로 바꿔치기된 상태**였다.
껍데기도 `gtag` 라는 이름의 함수를 제공하므로 **호출은 성공하고 인자도 그대로 보인다.**
그래서 내가 본 값은 전부 맞았고, 그 값이 아무 데도 안 갔을 뿐이다.

**같은 브라우저였다는 것이 두 번째 겹이다** — 사용자가 직접 눌러 본 것도 확장 프로그램이 깔린 그 크롬이라, 사람이 만든 이벤트도 같은 이유로 0 이었다.

## 3. 해결

**시크릿 창**에서 열어 같은 조작을 하니 넷이 다 도착했다 (`bi_entry` 4 · `bi_card_click` 2 · `bi_filter_apply` 1 · `bi_origin_exit` 1).
시크릿 창은 확장 프로그램이 기본으로 꺼져 있다.

**코드는 한 줄도 안 고쳤다.** 고칠 것이 없었다.

## 4. 예방

### 4.1. 세 층을 갈라 부른다

계측에는 확인 지점이 셋이고 이름이 비슷해서 뭉뚱그리기 쉽다.

| 층 | 무엇을 보나 | 무엇으로 |
| --- | --- | --- |
| ① 붙었다 | 산출물에 스크립트 · 표식이 있다 | `grep` · 단위 테스트 |
| ② 불렸다 | 브라우저가 함수를 호출했고 인자가 맞다 | 콘솔 · `dataLayer` |
| ③ 도착했다 | 수집처가 그것을 받았다 | 전송 요청 · **수집처 화면** |

**①과 ②를 보고 ③을 말하면 안 된다.**
이 회차에서 ①과 ②는 전부 맞았고 ③만 0 이었다.

### 4.2. 차단 여부는 이 둘로 가른다

```js
typeof window.google_tag_data   // 진짜 gtag.js 가 돌면 'object'
typeof window.ga                // 차단기 대체 스크립트가 흔히 만드는 전역
```

네트워크에서는 **`/g/collect` 요청이 있는가** 하나만 보면 된다.
`gtag/js` 가 200 으로 와도 그것은 태그 로더일 뿐이라 근거가 못 된다.

### 4.3. 계측은 차단되는 것이 정상이다

광고 차단기를 쓰는 방문자의 계측이 빠지는 것은 **고장이 아니라 그 사람의 선택**이다.
그래서 두 가지를 함께 한다.

- **고지에 적는다** — 소개 페이지에 「광고 차단 확장 프로그램을 쓰시면 이 수집은 그대로 차단되고, 그래도 사이트 이용에는 지장이 없습니다」 를 넣었다.
- **수치를 읽을 때 감안한다** — 방문자 수가 실제보다 적게 잡히며, 그 비율은 우리가 모른다.

### 4.4. 검증용 브라우저를 정해 둔다

이 저장소의 화면 검증은 사용자의 크롬으로 한다.
**그 크롬에는 확장 프로그램이 깔려 있고, 계측 검증에서는 그것이 측정 도구를 바꾼다.**
계측을 확인할 때는 **시크릿 창** 또는 확장 프로그램이 없는 브라우저로 한다.
