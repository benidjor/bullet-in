# 「이 기사는 왜 안 가져왔나」 한 질문에 층이 셋이었다 (2026-09-01)

이적시장 마감일에 사용자가 fmkorea 글 여섯 건의 주소를 주며 왜 수집되지 않았는지 물었다.
답은 하나가 아니었다.
여섯 건이 서로 다른 세 가지 이유로 화면에 없었고, 그중 하나는 애초에 수집돼 있었다.

이 문서는 그 갈래와 조사하며 밟은 함정 셋을 남긴다.

## 1. 답이 셋으로 갈렸다

| 갈래 | 건수 | 실제 |
| --- | --- | --- |
| 이미 수집돼 있었다 | 1 | 제목에 「온스테인」 이 있어 구단명이 아닌 검색 키워드에 걸렸다 |
| 회차가 아직 안 왔다 | 2 | 마지막 회차 (18:02 KST) 뒤에 올라왔다 |
| 검색에 안 걸렸다 | 3 | 제목에 구단명이 없어 후보 목록에 들어오지 못했다 |

**수집의 관문은 검색이다.**
fmkorea 어댑터는 사이트를 훑지 않고 `search.php` 결과만 후보로 삼는다.
검색에 안 걸린 글은 무관 글 필터에 닿기도 전에 사라진다.

여섯 건 전부 제목에 「아스날」 이 없었고, 그중 넷은 본문에만 구단명이 있었다.
남은 둘은 제목과 본문 어디에도 「아스날」 이 없고 「아스널」 만 있었다
— 무관 글 필터는 표기 세 종을 인정하는데 검색 키워드는 한 종뿐이었다.

## 2. 함정 하나 — 저장된 주소가 fmkorea 주소가 아니다

처음에 글 번호로 마트를 조회해 **여섯 건 모두 「없음」 으로 판정했다.**
틀렸다.

fmkorea 어댑터는 원문 접속에 성공하면 **리다이렉트를 따라간 뒤의 원문 주소**를 `url` 로 저장한다.

```python
stored_url = str(ro.url)      # adapters/fmkorea.py · _process
```

그래서 `WHERE url LIKE '%<글번호>%'` 는 **구조적으로 못 찾는다.**
수집된 글도 「없음」 이 나온다.

**시각으로 대조해야 한다.**
`published_at` 은 UTC 이고 fmkorea 게시 시각은 KST 라 아홉 시간 차이가 난다.
글 페이지의 `.rd_hd .date` 값에서 아홉 시간을 빼면 그대로 `published_at` 이다.
함께 보는 열은 `outlet` 과 `journalist` 다
— 말머리에서 가져온 값이라 원 제목과 대 보면 같은 글인지 확인할 수 있다.

## 3. 함정 둘 — 홈에 없다는 것이 사라졌다는 뜻이 아니다

이미 수집돼 있던 한 건은 첫 화면에서 안 보였다.
사라진 것이 아니라 **대표 카드의 관련 보도로 접혀 있었다.**

접은 것은 `promote_recent` 의 날짜 가드다.

```python
if day == rep_day:
    continue          # 그 날짜엔 대표 카드가 이미 서 있다
```

이 가드는 2026-08-28 에 들어갔고 근거는 「2분 차이의 같은 소식이 카드 두 장으로 선다」 는 실측이었다.
그런데 이번에는 접힌 쪽이 **더 진전된 소식**이었다.
대표는 `제안 · 협상` 이고 접힌 글은 `이적 합의` 였으며 둘의 시각 차이는 열두 시간이 넘었다.

**예외를 가를 기준은 시각이 아니라 단계였다.**
`transfer_stage.STAGE_ENUMS` 의 나열 순서가 곧 진행 순서라 새 문턱값이 필요 없었다.
PR #418 이 그 예외를 넣었고, 운영 데이터로 재니 그날 선 카드가 아홉에서 열둘로 늘고 보도 총수는 열여섯으로 그대로였다
— 접힘에서 꺼낸 것이지 기사를 만든 것이 아니다.

## 4. 함정 셋 — 조사 도구가 세 번 틀렸다

세 번 다 **데이터가 아니라 잣대가 틀렸고**, 매번 그럴듯한 「0건」 이 나왔다.

| 무엇 | 왜 틀렸나 |
| --- | --- |
| `grep -v "^    "` 로 출력을 다듬음 | 결과 줄이 정확히 네 칸 들여쓰기라 **찾던 것을 통째로 지웠다** |
| `.daygroup` 에서 날짜 머리글을 찾음 | 머리글은 `.daydiv` 에 있었다 |
| `find_next_sibling` 으로 그룹을 잡음 | `.daydiv` 는 형제가 아니라 **자식**이었다 |

**「0건」 은 「없다」 가 아니라 「내 잣대가 못 본다」 일 수 있다.**
찾는 것이 하나라도 걸리는지를 먼저 확인하고 나서 0을 결론으로 쓴다.

## 5. 고친 것과 남긴 것

- **PR #417** — 첫 검색의 대상 범위를 `title` 에서 `title_content` 로 넓히고 「아스널」 표기 변형을 키워드에 더했다.
21:03 회차에서 확인했고, 신규 적재 두 건이 **둘 다 제목에 구단명이 없는 글**이었다.
본문 대조로 경로까지 확정했다 (다른 키워드는 본문에도 없었다).
- **PR #418** — 단계가 나아간 후속 보도를 같은 날에도 카드로 세운다.
- **남긴 것** — 이적이 어떻게 끝났는지 알리는 글 (다른 구단행 · 무산) 이 여전히 대표 카드 뒤에 접힌다.
설계는 끝냈고 구현만 남았다 (안건 2π).
