# 원본에 없다던 발행 시각은 한 층 아래에 있었고, 수집 시각 간격은 짧게 나왔다 (2026-10-05)

- **영역**: 원본 저장소 (Mongo `raw_items`) / SLO-5 상한 근거 / 원본 워터마크
- **관련 안건**: 2ω 비수기수집기준 (조각 ⓒ) · 2κ 트윗원문흔들림
- **고친 것**: 문서 정정 (SLO-5 설계 §9.5 · #529) · 안건 2ω ⓒ 를 할 일 없이 닫음 · 코드 변경 없음
- **남은 일**: 원본 워터마크를 발행 시각 기준으로 볼지 (안건 2κ 와 함께)

## 1. 증상

안건 2ω 의 조각 ⓒ 는 「원본에 발행 시각을 남기자」 였다.
2026-10-02 SLO-5 상한을 고를 때 원본에 발행 시각이 없다고 보고 (7개 소스 모두 0건), 첫 수집 시각 (`fetched_at`) 의 간격으로 원문에 새 글이 없던 기간을 쟀기 때문이다.
SLO-5 설계 §9.3 에도 「원본 문서에 발행 시각이 없어」 라고 적혀 있었다.

2026-10-05 에 이 조각을 시작하려고 어댑터 코드를 먼저 읽었다.
어댑터 대부분이 원본에 `published` 나 `created_at` 을 이미 담고 있었다.

## 2. 원인 — 센 층이 틀렸다

10-02 의 측정은 원본 문서 최상위의 `published_at` 필드를 셌다.
그런 필드는 처음부터 없었고, 어댑터는 발행 시각을 한 층 아래 `raw_payload.published` (X 는 `raw_payload.created_at`) 에 담는다.

운영 `raw_items` 1,462건을 소스와 달로 나눠 다시 셌다.

| 범위 | 발행 시각이 있는 원본 |
| --- | --- |
| 2026-08 이후 · 모든 소스 | 100% |
| X 두 소스 | 처음부터 100% |
| 2026-06 · 07 의 일부 소스 | 비어 있다 (상세 페이지에서 발행 시각을 뽑기 전에 받은 원본) |

「없다」 는 결론이 안건 하나 (2ω ⓒ) 와 설계 문서의 근거 문장이 됐다.
발행 시각을 남기는 작업은 이미 8월에 끝나 있었다.

## 3. 덤으로 드러난 것 — 수집 시각 간격이 짧게 나왔다

발행 시각으로 공백을 다시 재 보니 Ornstein 의 값이 크게 달랐다.

| 소스 (2026-08 이후) | 수집 시각 기준 최장 공백 | 발행 시각 기준 최장 공백 |
| --- | --- | --- |
| Ornstein | 228h | 513h |
| Sky Sports | 219h | 210h |
| BBC Sport | 291h | 167h |

그 구간의 원본을 보니 같은 트윗이 여러 번 저장돼 있었다.

| 저장 시각 (UTC) | 본문 첫머리 | 주소 |
| --- | --- | --- |
| 08-30 15:03 | 🚨 없음 | 트윗 속 기사 주소 |
| 09-06 03:00 | 🚨 있음 | 트윗 주소 |
| 09-06 18:00 | 🚨 있음 | 트윗 속 기사 주소 |
| 09-16 06:00 | 🚨 없음 | 트윗 주소 |

원본 저장소는 내용 해시 (`content_hash` = 본문 + 주소) 로 중복을 거른다.
본문 맨 앞 이모지와 주소의 조합이 바뀔 때마다 해시가 달라져 옛 트윗이 「처음 보는 원본」 이 됐다.
그래서 새 트윗이 없던 기간에도 수집 시각이 찍혀 공백이 끊겨 보였다.

## 4. 영향

| 자리 | 영향 |
| --- | --- |
| SLO-5 상한 근거 (§9.3) | 「Ornstein 240h 는 지난 석 달을 대입하면 오탐이 없다」 가 성립하지 않는다 · 상한 값은 유지 (이적 필터 전 타임라인 목록은 저장된 트윗보다 자주 바뀐다 · 저장된 마지막 트윗이 09-25 인데 목록 지문은 10-04 에 두 번 바뀌었다) |
| 원본 워터마크 (`RawStore.source_watermarks`) | 옛 트윗이 다시 저장될 때마다 앞으로 움직인다 · 수집 현황 신선도 표의 「조용함 · 정상」 과 「새 원본 경과」 미터, 끊김 알림의 「마지막 수집」 줄이 실제보다 좋게 보일 수 있다 |
| SLO-5 값 · 끊김 알림 발송 | 없다 · 끊김은 목록 응답과 목록 지문으로만 정한다 |
| 재번역 비용 | 작다 · 09-21 에서 10-04 까지 원본 재저장 5건 · 그 기간 해시가 바뀐 X 기사 2행 (한 행은 7번 바뀜) |

## 5. 교훈

- **「없다」 를 안건으로 만들기 전에 한 층 아래 (payload · 중첩 필드) 를 본다.** 최상위만 센 조회는 빈 결과를 「없음」 으로 보여 준다.
- **해시가 흔들리는 소스에서 `fetched_at` 은 「새 글이 나온 시각」 의 대리 지표가 되지 못한다.** 발행 시각이 있으면 그것을 쓴다.
- **위쪽 한계 논리는 전제를 다시 본다.** 「새 원본이 들어오면 목록이 바뀌었다」 는 재저장이 있으면 깨진다.
