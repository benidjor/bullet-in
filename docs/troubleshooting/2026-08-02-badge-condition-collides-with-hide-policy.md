# 배지 조건을 좁혔더니 숨김 정책과 겹쳐 배지가 사라졌다 (2026-08-02)

링크 선수 배지를 "이적 기사가 아닌 글" 로 좁혔더니, 그 조건에 걸리는 글이 곧 기본 숨김 대상이었다.
배지가 붙은 카드 8개가 전부 `display:none` 으로 렌더돼, 독자가 배지를 볼 방법이 사라졌다.
사용자가 "이 기사를 배포판에서 찾을 수 없다" 고 물어서야 드러났다.

## 1. 무슨 일이 있었나

- 배지의 취지를 다시 정하면서 조건을 두 번 좁혔다.
아스날 소속 인물이 연결된 글 제외 (PR #195) · 이적 기사 제외 (PR #196).
- 그런데 이적과 무관한 글 (`transfer_stage='other'`) 은 2026-06 부터 목록에서 기본으로 숨겨진다 (PR #22).
사이드바에서 "기타" 를 켜야 나타난다.
- 두 규칙이 겹치면서 배지를 붙일 글이 곧 숨기는 글이 됐다.
배지는 렌더되지만 그 카드가 화면에 없다.

배지의 목적이 "왜 이 글이 아스날 피드에 있는지 설명" 하는 것인데, 정작 그 글이 피드에 보이지 않았다.

## 2. 확인이 빗나간 지점

배지 변경을 반영할 때마다 배포판을 grep 으로 확인했는데, 처음 두 번은 **상세 페이지**를 봤다.
배지는 목록 카드에만 렌더되므로 상세 페이지 grep 은 애초에 아무것도 증명하지 못한다.
빈 결과를 "배지가 규칙대로 빠졌다" 로 읽어 이상을 놓쳤다.

목록 페이지에서 카드 단위로 확인하니 바로 드러났다.

```python
for m in re.finditer(r'<span class="ctx">([^<]+)</span>', html):
    seg = html[max(0, m.start() - 2500):m.start()]
    tag = seg[seg.rfind('<a class="item'):]
    print(m.group(1), "숨김:", "display:none" in tag)
```

## 3. 표시 판정이 두 곳에 있다

고칠 때 한 곳만 고치면 절반만 해결된다.

- **서버 렌더** (`_cards.html.j2`) — 첫 화면의 카드 표시 여부.
- **필터 JS** (`app.js` 의 `applyFilters`) — 독자가 검색 · 필터를 건드린 뒤의 표시 여부.
이쪽은 `data-stage` 를 다시 보고 판정하므로, 서버에서 보이게 해도 필터를 한 번 누르면 도로 숨는다.

그래서 PR #202 는 양쪽을 함께 고쳤다.
서버가 배지 카드에 `data-ctx` 표식을 남기고, JS 는 그 표식이 있으면 기타 숨김 판정에서 뺀다.
판정 근거를 JS 가 다시 계산하지 않게 해 규칙이 두 벌로 갈라지는 것도 막았다.

## 4. 재발 방지

- **서빙 조건을 좁힐 때는 기존 표시 정책과 어떻게 맞물리는지 먼저 본다.**
숨김 (기타) · 롤업 (가십 루머 고정) · 접기 (같은 사건 묶음) 가 이미 있고, 새 조건이 이들과 겹치면 기능이 조용히 무력화된다.
- **화면 확인은 실제로 보이는 자리에서 한다.**
배지 · 배경색처럼 카드에만 있는 요소는 목록 페이지에서, 본문 · 원문 링크처럼 상세에만 있는 요소는 상세 페이지에서 확인한다.
- **표시 판정이 서버와 JS 두 곳에 있다는 것을 기억한다.**
한쪽만 고치면 첫 화면에서만 맞고 독자가 필터를 건드린 뒤에는 어긋난다.
