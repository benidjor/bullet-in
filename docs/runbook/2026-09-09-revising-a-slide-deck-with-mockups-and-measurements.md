# 런북 — 슬라이드를 고칠 때의 순서 · 목업, 조각 반영, 열별 측정, 캡처

소개 슬라이드 (저장소 밖 · `v9_build`) 한 장을 고쳐서 사용자 확인까지 가는 절차다.
2026-09-09 에 4 ~ 20장을 세 차례 통독받으며 굳어진 순서이고, 도구는 전부 `v9_build/` 에 있다.

## 1. 목업을 먼저 만든다

- 슬라이드 HTML 을 손으로 고치지 않는다.
  덱은 조각 `bullet_in_v2.html` 에서 `build_v9.py` 로 조립되므로, 조립본을 고치면 다음 조립 때 사라진다.
- 구조가 바뀌는 수정 (표를 도식으로 바꾸기, 열 배치 바꾸기) 은 `mockups/head.html` (덱 `<style>` 전체) 뒤에 슬라이드 하나를 붙인 목업으로 만든다.
- `shoot_any.py <dir> <name>` 으로 찍어 넘침을 확인하고 캡처를 사용자에게 보낸다.
  사용자 확인 전에는 조각을 건드리지 않는다.
- 두 안 이상을 비교할 때는 같은 장을 같은 조건으로 찍어 나란히 보낸다.
  요약 띠 색 같은 취향 결정은 실제 조립본 (청록 상자가 있는 장) 에서 비교해야 판단이 선다.
- 목업 머리 (`mockups/head.html`) 는 덱의 `<style>` 만이 아니라 조립기가 `</style>` 앞에 끼워 넣는 규칙 줄까지 담아야 한다.
  그 줄에 16장 공통 목록 규격 (`.bi`) 이 있어서, 빠지면 목업이 덱보다 짧게 재어진다 (2026-09-11 트러블슈팅).
  조립기의 규칙 줄을 바꿨으면 머리 파일의 마지막 규칙 줄도 같은 문자열로 바꾼다.
  검증은 덱과 목업을 Playwright 로 열어 같은 장의 `li` 글자 크기와 높이를 나란히 찍어 보는 것이다.

## 2. 조각에 반영하고 조립한다

```bash
cd ~/Documents/01_DE_project/bullet-in          # Playwright 가 이 저장소 venv 에 있다
B="$HOME/Documents/obsidian-vault/01 Projects/01-04 이력서/v9_build"
(cd "$B" && python3 build_v9.py)                 # 조립 · id 순서 · 목차 도달 검산
uv run python "$B/shoot.py"                      # 41장 넘침 (scrollHeight)
uv run python "$B/cols.py" 9 10 12               # 넘친 장의 열별 바닥
```

- `build_v9.py` 는 조각 id 순서 (`order`) 대로 번호를 다시 매긴다.
  장을 끼워 넣으면 `N_NEW` 와 목차 행 번호를 함께 밀어야 하고, 비교 장은 코드에 번호가 고정돼 있어 손으로 바꾼다.
- 조각 안의 쪽 번호 참조 (「17쪽」 같은 것) 도 함께 민다.

## 3. 넘침은 열별로 잰다

- `shoot.py` 의 넘침은 장 전체 값이라 원인을 안 가르쳐 준다.
  `cols.py` 가 찍는 열 바닥과 자식 바닥을 보고 어느 열의 무엇이 밀었는지 확인한다.
- 내용 한계는 720 − 그리드 아래 여백이다.
  대부분 14px 라 706 이고, 처음 v8 값은 24px 였다.
- 문장을 줄여도 값이 그대로면 CSS 를 의심한다.
  사례는 `docs/troubleshooting/2026-09-09-slide-overflow-came-from-css-not-sentences.md`.
- 왼쪽 열이 넘치고 오른쪽 열이 비면 지표 상자나 숫자 카드를 오른쪽 열 아래로 옮기는 것이 문장을 줄이는 것보다 낫다.
- 인라인 SVG 의 `<style>` 은 문서 전체에 적용되므로 클래스 이름에 장별 접두어를 붙인다 (`.glb` · `.xb` · `.dpb`).
  같은 이름이 덱에 몇 개인지는 `grep -o '\.이름{[^}]*}' 덱.html | sort | uniq -c` 로 센다.
- 도식 안 글자가 상자를 넘는지는 눈이 아니라 `getBBox()` 로 잰다.
  글자마다 오른쪽 끝 좌표와 그 글자를 품은 상자의 오른쪽 변을 찍어 비교하면 한 번에 다 보인다 (7장 ERD · 15장 도식에서 씀).
- 문장을 줄여도 값이 그대로면 어느 항목이 두 줄인지 캡처로 본다.
  한 단어가 다음 줄로 넘어간 항목은 괄호 하나만 떼도 한 줄이 된다.

## 4. 문장 규칙 (통독에서 굳어진 것)

- 항목은 「`·`」, 하위 항목은 「`→`」 표식뿐이다.
  문장 첫머리에 화살표를 두지 않고 항목 안에서 `<br>` 로 끊지 않는다.
- 「`·`」 은 짧은 명사 나열에만 쓰고 절과 절 사이는 「`,`」 다.
- 「`→`」 는 흐름, 「`⇒`」 는 결론이다.
  「`⇒`」 로 시작하는 결론 줄은 표식 없는 하위 항목 (`sub num`) 으로 두고 청록으로 강조한다.
- 명사형 종결과 「—」 금지를 지키고, 「↓」 같은 기호는 대체 서체로 찍히므로 「단축」 같은 말로 푼다.
- 내부 용어는 세션 메모리 `external-audience-terms` 의 표로 한 번 걸러 낸다.
- 「`·`」 은 짧은 명사 나열에만 쓴다.
  절과 절 사이, 캡션 · 코드 라벨 · 표 안의 절은 「,」 다.
  2026-09-10 통독에서 캡션 · 코드 라벨 · 표 안 스물여섯 곳이 「`·`」 로 이어져 있어 전부 바꿨다.
- 강조는 두 단계다.
  청록 굵게 (`.tb`) 는 요약 띠의 핵심, 「왜」 절의 상위 항목, 「해결」 절 전부에 쓰고, semibold 검정 (`.sb`) 은 「문제」 절과 「왜」 절의 하위 항목에 쓴다.
  규칙으로 한 번 배정하고 사용자가 짚은 자리만 개별로 바꾼다.
- 다른 장을 가리킬 때는 「N쪽」 이 아니라 「슬라이드 N」 이고, 클릭하면 이동하도록 `<a href="#slide-N">` 을 건다.
  SVG 캡션 안에서는 `<a>` 로 감싼 `<tspan>` 을 쓴다.
- 예시는 「예)」 로 시작하고, 표 안에서 줄이 넘어가면 걸린 들여쓰기 (`padding-left:1.4em; text-indent:-1.4em`) 로 둘째 줄을 들인다.
- 하위 항목에 표식이 필요 없을 때 (① ② ③ 나열) 는 `sub nomark` 클래스로 화살표를 뺀다.
- 구어체 (긁다 · 돌다 · 겪다 · 뒤지다 · 뚫리다) 는 검색어 목록으로 훑어 걸러 낸다.
- 수치는 저장소나 같은 날 실측에 닿아야 한다.
  이번 회차에서 co-author 커밋 수를 `git log` 로 다시 세어 586 이 587 로 바뀌었다.

## 5. 캡처를 보낸다

- 바뀐 장만 `shots/slide-NN.png` 를 보낸다.
  한 번에 여섯 장 안팎이 읽기 좋다.
- 대시보드 캡처는 창을 KPI 카드와 차트가 보이는 구간으로 옮긴다 (`object-position`).
  원본 캡처가 1040 × 1500 이라 위 절반은 설명 글뿐이다.
- 사이트 캡처는 양옆 여백을 잘라 확대한다 (`width:127%`, `margin-left:-13.5%`).
- Airflow 화면은 VM 루프백에만 묶여 있어 SSH 터널 (`-L 8081:127.0.0.1:8080`) 로 연다.
  터널과 비밀번호 파일 읽기는 auto mode 분류기에 막히므로 사용자가 `!` 로 직접 연다.
  Playwright 로 로그인해 찍는 스크립트도 막히며, 사용자가 허용한 뒤 비밀번호를 스크립트 파일에 두고 돌린 다음 그 파일을 지운다.
  그리드 패널과 상세 패널 사이 경계를 끌면 일정 폭을 넘길 때 상세 패널이 통째로 접히므로, 접힌 상태에서 찍고 태스크 이름 열과 실행 열을 잘라 붙인다 (Pillow 는 `uv run --with pillow`).

## 6. 목업을 조각에 옮긴다

- 목업 파일에서 `<div class="sw" id="slide-NN">` 부터 `</body>` 앞까지를 잘라 조각의 같은 장 블록 (다음 `<!-- ═` 주석 앞까지) 과 바꾼다.
  `id="slide-NN"` 은 조각 id (`K` · `L` · `M`) 로, `<div class="pg">NN</div>` 은 `0` 으로, 이미지 경로 `../../portfolio_assets/` 는 `portfolio_assets/` 로 되돌린다.
- 옮기기 전에 목업 SVG 의 클래스 이름이 덱의 다른 클래스와 겹치는지 본다.
  15장 도식의 `.kw` 는 코드 블록의 `.code .kw` 와 겹쳐 접두어를 바꿨다.
- 옮긴 뒤에는 41장 전체를 다시 잰다.
  목업이 0 이어도 덱에서 넘칠 수 있고, 2026-09-11 에는 16장 16px · 17장 31px 가 그렇게 나왔다.
