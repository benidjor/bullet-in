# 소제목 근거로 주역이 된 귀속 눈검수 (2026-08-13)

선수 페이지에 남의 기사가 실리는지 사람이 확인하는 절차다.
역할 규칙은 제목이나 소제목에 이름이 있으면 주역으로 보는데, 소제목에 이름이 있다고 그 절이 그 사람 이야기인 것은 아니다.

## 1. 왜 사람이 봐야 하나

같은 증상을 내는 유형이 셋이었고 **둘은 규칙이 막게 됐다** (2026-08-13).

| 유형 | 실물 | 처리 |
| --- | --- | --- |
| 소제목이 본문과 무관 | `ad4e18de` — 소제목에만 은와네리가 있고 본문은 전부 기마랑이스 이야기 | 규칙 — 소제목은 그 절 본문에도 이름이 나올 때만 근거 |
| 대체 대상 | `b8055b5b` — 촐리스 영입 기사에서 트로사르가 비교 기준점 | 규칙 — 이름 끝 여섯 글자 안에 「대체자」 가 오면 근거 아님 |
| **인용문 소제목에 이름이 스쳐 듦** | `c898d75c` — 「"아스날은 두에나 바르콜라로 넘어가야 한다"」 · 절 안에 그 한 문장뿐 | **규칙 없음 — 이 절차의 대상** |

세 번째에 규칙을 못 붙인 것은 기계 지표가 정당 판정과 함께 걸리기 때문이다.
따옴표 소제목은 같은 기사 안에서도 콘사 (정당) 와 두에 (틀림) 를 못 가르고, 절 길이는 본인 비중과 무관하며, 소제목의 이름 개수로 가르면 「로즈 감독, 크루피 · 스콧 · 라얀 잔류 자신」 처럼 정당한 절이 함께 무너진다.

**틀렸을 때의 방향은 안전한 쪽이다** — 남의 기사가 선수 페이지에 남는다.
본인 기사가 사라지는 쪽이 아니므로 배포를 막을 사유는 아니고, 쌓이면 잡음이 되므로 주기로 훑는다.

## 2. 대상 뽑기

`hit` 은 `_squash` 로 띄어쓰기를 지운 뒤 한글 후보를, `_fold_latin` 으로 라틴 후보를 부분 문자열 검사하는 함수다 (`roster.decide_role` 안의 것과 같다).

## 3. 판정 기준

**제목으로 판정하지 않는다.**
그 소제목이 여는 절의 본문을 읽고 **그 절이 그 사람에 관해 새 사실을 보도하는가**를 묻는다.

| | 정당 | 틀림 |
| --- | --- | --- |
| `564c3373` 크루피 | 감독의 전용 발언 — 「크루피는 지난 시즌 크게 성장했고 그에게는 한계가 없다」 | |
| `d30835af` 트로사르 | 본인 이적을 사실로 보도 — 「베식타스로 떠났다」 | |
| `b8055b5b` 트로사르 | | 촐리스와 유형 · 부상 이력 · 성격이 비슷하다는 서술뿐 |
| `c898d75c` 두에 | | 「두에나 바르콜라 영입을 시도해야 한다」 한 문장 |

경계가 가까운 두 건을 나란히 두면 기준이 선다.
`d30835af` 는 소제목이 「트로사르 이적과 마르티넬리 이적설」 이고 첫 문장이 그의 이적을 보도한다.
`b8055b5b` 은 그의 이적을 이미 지난 일로 두고 촐리스를 재는 데만 쓴다.

## 5. 함정

- **모집단을 `article_players` 전량으로 잡지 말 것.**
2026-08-13 실측으로 전량 기준 84행 · 표시 쌍 기준 36행이었다.
차이는 선수 페이지가 없는 인물 (감독 · 이적 얘기 없는 주전) 이다.
- **규칙이 막게 된 두 유형이 다시 목록에 뜨면 규칙이 깨진 것이다.**
소제목에만 이름이 있는 행과 「대체자」 바로 앞 이름은 이제 규칙이 주역으로 안 올린다.
- **손으로 고친 값은 규칙과 같은 방향일 때만 오래 산다.**
소급 재추출은 대상 기사의 `article_players` 행을 지우고 다시 만들므로 (`reextract_article_players.py`), 규칙이 반대 값을 계산하면 되돌아간다.
